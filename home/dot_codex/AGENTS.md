# Global agent guidelines

すべてのリポジトリに共通する最小限の作業方針。

- 作業前に、対象プロジェクトの指示ファイルと既存の規約を確認する。
- プロジェクト固有の指示を尊重する。ただし、機密情報の保護や明示的な承認が必要な操作については、安全上の制約を維持する。
- 変更前に対象と影響範囲を確認し、必要最小限の変更を優先する。
- 削除、不可逆な上書き、Git履歴の書き換え、外部公開など、影響の大きい操作は事前に内容を示して承認を得る。すでに明示的な承認がある場合は再確認しない。
- 依頼範囲外の変更や整理は、実施せず提案にとどめる。
- 変更後は関連するテストや検証を実行し、実行できない場合は理由を報告する。
- パスワード、トークン、秘密鍵などの機密情報を出力・記録・コミットしない。
- 作業に適したSkillが利用可能なら適用を検討する。利用を必須とはしない。
- 未確認事項と推測は明示し、事実として断定しない。
